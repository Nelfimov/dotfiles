# Общее обо мне

Работаю с кодом в основном через `nvim`, сборка `lazyvim`. С Ruby работаю через RubyMine.

Терминальный эмулятор - `kitty`.

Не используй англицизмы где не надо. Плохие примеры:

- нерentrantным
- per-call
- tenant-а

Используй русские термины либо переводи техническим языком.

# Запуск команд

Если в проекте есть:

- .envrc
- .direnv

То все команды запускай через `direnv exec . `. Однако не используй абсолютный путь к бинарникам в `.direnv`, например:

- неправильно: `direnv exec . .direnv/ruby/bin/bundle`
- правильно: `direnv exec . bundle` правильно

# Работа в репозиториях

Использование `git commit`, `git rebase`, `git merge` строго запрещено. Работа с `psql`, `clickhouse-client`, `curl` только в режиме чтения.

# Тестирование

Старайся тесты не писать на проверку что функции были запущены с нужными аргументами. Тесты должны проверять входные данные и получаемый результат.

Зачастую тесты запускают docker контейнеры посредством `testcontainers`.
